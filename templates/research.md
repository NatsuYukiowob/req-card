# Template: research

Use for: investigations that end in a report or recommendation, not a code
change.

## Must-clarify (ask, or state as an Assumption)

- What decision does this research feed? (What will be done with the answer?)
- Depth: quick scan, or verified deep-dive?
- Which sources count (official docs only? community posts OK?)
- Deliverable format, and where it lands.

## Card skeleton

**Goal:** `<the question to answer, one sentence>`

**Scope:**
- In: `<sub-questions to cover>`
- Out: `<explicitly not investigated>`

**Environment (output destination):** `<no runtime env for research — record where the deliverable lands: file path / doc / chat reply>`

**Acceptance (EARS):**
- WHEN the report is delivered THE SYSTEM SHALL `<answer each in-scope sub-question, with cited sources>`

**No-go:** `<e.g. no paid sources, no vendor contact, no test installs on shared hosts>`

**Assumptions:** `<inferred scope cuts, freshness requirements>`
