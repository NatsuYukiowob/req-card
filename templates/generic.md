# Template: generic

Use for: any hands-on task no other template fits. Bare six-field card.

## Must-clarify (ask, or state as an Assumption)

- What exactly changes, and where?
- How will we know it worked?
- What must NOT be touched?

## Card skeleton

**Goal:** `<one sentence — the outcome the user wants>`

**Scope:**
- In: `<what will be done>`
- Out: `<what will explicitly NOT be done>`

**Environment:** `<system / repo / branch / host / cluster this touches>`

**Acceptance (EARS):**
- WHEN `<trigger or check>` THE SYSTEM SHALL `<observable behavior>`

**No-go:** `<files, resources, or operations that must not be touched>`

**Assumptions:** `<everything inferred rather than user-stated — for the user to veto>`
